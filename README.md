# Landing Page — Plataforma de Oportunidades

Estrutura estática pronta para hospedagem em Vercel:

- `index.html`
- `style.css`
- `script.js`

## Publicação na Vercel

1. Crie um repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Na Vercel, importe o repositório.
4. Framework Preset: `Other`.
5. Build Command: deixe vazio.
6. Output Directory: deixe vazio.
7. Deploy.

## Antes de divulgar

Substitua os links `#` pelos URLs reais de cadastro/login da plataforma.

O texto evita promessas de renda garantida. Valores, comissões, condições e regras reais devem ser informados de forma transparente.
